# Autonomous Object Detection Pipeline

## Overview
A command-line executable object detection system utilizing the YOLOv8 architecture pre-trained on the COCO dataset[cite: 1]. The pipeline accurately locates and labels multiple overlapping objects in unconstrained environments and outputs annotated bounding boxes[cite: 1].

## Features
* **Command-Line Processing:** Streamlined CLI for image ingestion and processing[cite: 1].
* **Pre-trained Object Detection:** Implements anchor-free bounding box regression and classification[cite: 1].
* **Automated Visualization:** Generates annotated images with bounding boxes and confidence scores[cite: 1].

## Technologies & Tools Used
* Python
* PyTorch
* OpenCV
* Ultralytics YOLOv8
